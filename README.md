# E-Commerce-Site

Un site e-commerce simple permettant de consulter un catalogue de produits, gérer un panier, s’authentifier et procéder au paiement.

## 🧩 Description

Ce projet sert de base pour un site e-commerce démonstratif.  
Il contient des pages pour l’accueil, le catalogue, l’authentification, le panier et le paiement.

## ⭐ Fonctionnalités principales

- Affichage du catalogue  
- Page de détails produit  
- Inscription et connexion  
- Gestion du compte client  
- Panier (ajout / suppression)  
- Paiement  
- Pages Contact et À propos  
- Interface responsive

## 🛠 Technologies utilisées

- HTML  
- CSS  
- JavaScript

## 🚀 Installation

1. Cloner le projet  
   `git clone https://github.com/Zenbx/E-Commerce-Site-.git`

2. Ouvrir le dossier dans VSCode ou un autre éditeur

3. Ouvrir le fichier `Accueil/accueil.html` dans un navigateur  
   *(ou lancer un serveur local si nécessaire)*

## 📘 Usage

- Consulter le catalogue  
- Voir les détails des produits  
- S’inscrire / se connecter  
- Gérer son panier  
- Finaliser son achat
